05Edge Case Reference Matrix
The engine's fixed handling for the four documented boundary anomalies. Highlighted cards indicate which case(s) the current log triggered.

Mid-Shift Break Scans

Logs between IN_Window.end and OUT_Window.start are ignored — only absolute MIN(IN) and MAX(OUT) are recorded.

→ Filtered, no status impact

Single Punch (Forgot Clock-Out)

Only firstInTime matched; no valid lastOutTime found in OUT_Window.

→ INCOMPLETE, netHours = 0

Early Clock-In Outside Window

Punch occurs before inWindowStartOffset.

→ Ignored by engine, flagged for manual review

Shift Overrun (Extended OT)

Clock-out exceeds outWindowEndOffset.

→ INCOMPLETE until manager override
